# Build a Notes App

Build a notes-taking web application with a clean card-based UI.

## Features
- Create new notes with a title and body text (textarea)
- Display notes as cards in a responsive grid (2–3 columns)
- Edit existing notes by clicking an edit icon on the card
- Delete notes with a delete button and a confirmation dialog
- Search notes in real-time by title or content (search bar at top)
- Color-label notes: 5 pastel color options per note
- Show creation date on each card ("Jan 15, 2025")
- Empty state illustration when no notes exist
- Persist all notes in localStorage

## Design
Off-white background (#f8f7f4). Cards have soft shadows and rounded corners.
Each card's top strip shows its chosen color. Subtle hover lift effect.
Google Fonts: "Lato" for UI, "Caveat" for note body text (handwriting feel).

## Technical
No backend. HTML/CSS/JS with localStorage.
Files: index.html, style.css, app.js
